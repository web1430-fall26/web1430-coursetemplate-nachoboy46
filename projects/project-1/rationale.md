# Thoughts

This project took a long time. I learned a lot during it. At the start I struggled to do a lot, but by the end I was able to write init functions and html and stuff often with help from the internet, at least until I ran into some weird random bug. I designed this for the magic the gathering corporation. I think ovo is a good choice because it's very legible and formal. For the components, I gave each component it's own render section so I could repeatedly make new examples of it without too much difficulty. The hardest interactive pattern was probably tabs, I struggled a lot to get them to pop back up, but once I remembered I could use aria-controls that helped a lot. A developer would need to know the class names and ids for the things I built in order to match them to his own components.
