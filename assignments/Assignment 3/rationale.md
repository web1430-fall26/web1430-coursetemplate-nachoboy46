#  Rationale

The most challenging part for me was the second one. I alreay made something very similar to it previously, but it 
just so complex and so hard to wrap my brain around, but that did end up making the third part a lot easier because
I had to research CSS identifiers.
I implemented keyboard accesibiltiy through adding a keydown listener and focusing on specific tabs, and I had to learn about how focusing on a button differs from just clicking on a button.
I used event delegation in all three of the sections, and they were all the right choice because it minimized the number of event listeners I needed to use.
If I made this a real project I would want to make a function that automatically creates the html objects and appends them,
so I don't have to go through and manually edit the html every time I want something new.
